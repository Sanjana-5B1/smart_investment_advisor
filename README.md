## 📖 Overview

Smart SIP Investor is a web-based financial planning application that helps users estimate the future value of their Systematic Investment Plans (SIP) based on their financial goals, savings, and expected returns.

The platform simplifies long-term investment planning through interactive calculations, graphical insights, and personalized investment recommendations.

---

# ❓ Problem Statement

Many first-time investors struggle to determine:

- How much they should invest monthly.
- How investments grow over time.
- Whether their financial goals are achievable.
- How different investment durations affect returns.

Smart SIP Investor addresses these challenges by providing an easy-to-use platform for SIP planning and investment analysis.

# 🚀 Getting Started

## Prerequisites

- Python 3.x
- pip

---

## Clone Repository

```bash
git clone https://github.com/srinidhi0506/smart_investment_advisor.git

cd smart_investment_advisor
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Run Application

```bash
python app.py
```

---

## Open Browser

```text
http://127.0.0.1:5000/
```
